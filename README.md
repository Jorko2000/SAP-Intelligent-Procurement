# SAP Intelligent Procurement Platform (SIPP)

## Overview
Enterprise-grade procurement platform designed for SAP BTP environments.

## Architecture
- CAP-style Node.js backend
- Event-driven design
- AI-based approval scoring
- PostgreSQL persistence
- Docker & Kubernetes ready

## Key Features
- Automated approval recommendations
- Clean service separation
- SAP-compliant architecture
- Scalable cloud deployment

## Tech Stack
Node.js | SAP CAP Concepts | PostgreSQL | Docker | Jenkins | Kubernetes

## Run Locally
docker-compose up
